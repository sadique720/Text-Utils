# Text-Utils

A small Django-based text utility project for processing and analyzing text input.

## Overview

This project helps practice backend development and simple web application workflows using Python and Django.

## Features
- Character count
- Word count
- Sentence count
- Remove extra spaces
- Uppercase and lowercase conversion
- Basic text transformation utilities

## Tech stack
- Python
- Django
- HTML
- CSS
- Bootstrap

## How to run
```bash
pip install django
python manage.py runserver
```

Then open the local server in your browser.
